# Quiz Solving Application (MERN Stack)

### How to Run the Project:

1. **Running the Back-end:**
   - Open a terminal in the `backend` folder.
   - Run the command: `npm install` (to install dependencies).
   - Run the command: `npm start` (the server will start on port 3000).

2. **Running the Front-end (React):**
   - Open a second terminal in the `frontend` folder.
   - Run the command: `npm install` (to install dependencies).
   - Run the command: `npm run dev` (or `npm start`, depending on your configuration).

*Note: The database is deployed in the MongoDB Atlas cloud, and network access is open from all IP addresses. Questions are fetched automatically from the Open Trivia API when the quiz is started for the first time.*
